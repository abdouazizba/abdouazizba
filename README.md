<h2>Abdou Aziz BA</h2>

<code>Freelance Full-Stack Developer • APIs & Business Tools • Automatisation</code>


I'm a freelance full-stack developer building web and mobile applications from start to finish. I work mainly with JavaScript and TypeScript, using React and Next.js on the frontend, React Native and Flutter for mobile, and Node.js / Express or .NET on the backend. I handle everything from database design and REST APIs to user interfaces, deployment and monitoring.

I care a lot about understanding how my clients actually work before writing any code. The best software is the one that fits the business, not the other way around, so I focus on building tools that are simple to use, reliable and easy to maintain over time.

I'm especially interested in AI and automation. I integrate AI models into applications and workflows to save time on repetitive tasks, speed up data processing and give teams better insight into their activity.

My goal is to help entrepreneurs, small businesses and teams turn their ideas into real products, whether it's a new app, a custom back-office, or connecting the tools they already use.
